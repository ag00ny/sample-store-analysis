# Superstore Sales Analysis
Анализ продаж розничной сети

## Описание проекта
Анализ продаж розничной сети Superstore (9994 заказа) с целью выявления прибыльных и убыточных направлений, влияния скидок на прибыль и динамики показателей по годам.

## Инструменты
- Google Sheets (очистка данных, сводные таблицы, дашборд)

## Ключевые выводы
- Скидки выше 30% приводят к убыткам
- Прибыль почти удвоилась с 2014 по 2017 год
- Technology — самая прибыльная категория
- Категория Furniture при высоких продажах ($742 000) генерирует низкую прибыль ($18 451).
- Подкатегории Tables, Supplies и Bookcases работают в минус
- Регион Central является самым проблемным: самые низкие продажи ($501 240), высокая средняя скидка (24%) и отрицательная маржа (-20,1%)

## Рекомендации
- Ограничить максимальный размер скидки 20–25%, особенно в категории Furniture. Если скидка выше начинает расти убыток.
- Пересмотреть ассортимент убыточных подкатегорий
- Сфокусироваться на Technology и Office Supplies
